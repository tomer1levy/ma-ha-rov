# מה הרוב?

משחק דילמות והימורים קבוצתי בעברית. תומך במנחה במחשב ובשחקנים המצטרפים דרך דפדפן בטלפון (כולל רשת סלולרית).

הפרויקט נפרס ל-Render מתוך חבילת מקור דחוסה שנמצאת בקובצי `bundle.part0` ו-`bundle.part1`. קובץ `Dockerfile` משחזר אותה במהלך הבנייה.

לאחר הפריסה: פתחו `/host` ליצירת חדר; המשתתפים סורקים את קוד ה-QR או פותחים `/play`.

החדרים נשמרים בזיכרון השרת בלבד ונמחקים עם הפעלה מחדש. מומלץ לערוך את השאלות לפני פתיחת המשחק.
